## Sobre mim

Atuo profissionalmente como **Analista de Banco de Dados**, mas meu trabalho também envolve desenvolvimento de sistemas internos, automação de processos e suporte técnico avançado.

Gosto de transformar rotinas manuais em soluções simples de operar, com interface, logs, validações, atualização e distribuição. Meus projetos conectam banco de dados, desenvolvimento e conhecimento operacional para resolver problemas reais de empresas.

## SOLPPE

**SOLPPE** significa **Solução Parceira Para Empresas**. É a marca que utilizo em projetos criados para reduzir tarefas manuais, padronizar processos e tornar rotinas empresariais mais confiáveis.

## Como penso as soluções

- Começar pelo problema operacional e pela experiência de quem vai usar.
- Automatizar com validações, logs e caminhos claros de recuperação.
- Entregar algo simples de instalar, atualizar e manter.
