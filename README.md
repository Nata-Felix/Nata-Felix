## ✦ Projeto em destaque: Zênite

<a href="https://github.com/Nata-Felix/Zenite">
  <img src="https://raw.githubusercontent.com/Nata-Felix/Zenite/main/docs/images/banner.jpg" alt="Zênite: seus agentes de IA trabalhando juntos, num canvas infinito" width="100%">
</a>

**[Zênite](https://github.com/Nata-Felix/Zenite)** é um canvas infinito para Windows onde agentes de IA de terminal
(Claude Code, Codex, Antigravity, Grok) trabalham juntos, ao lado das notas, tabelas, sites, arquivos e fluxos
do projeto. Um agente coordenador, o **Sol**, recebe o pedido, monta a equipe e acompanha o andamento.

<p align="center">
  <img src="https://raw.githubusercontent.com/Nata-Felix/Zenite/main/docs/images/sol-construindo.gif" alt="O Sol recrutando terminais e preenchendo a tabela de bugs" width="80%">
</p>

- **Orquestração de agentes:** CLI própria (`zn`) para os agentes lerem e escreverem no canvas, conversarem entre si e pedirem atenção.
- **Automação visual:** fluxos com agendamento, condições, aprovação humana, webhooks HTTP e código Python/JavaScript.
- **Segurança por padrão:** cada agente só acessa o que está ligado a ele, permissões configuráveis e isolamento opcional em Docker.
- **Produto completo:** instalador, atualização automática (completa e leve), backups e mais de 300 testes automatizados.

<sub>Electron · TypeScript · React · Node.js · ConPTY · Git · Docker · GitHub Actions</sub>

## O que eu faço

Minha carteira diz **Analista de Banco de Dados**. Na prática, atuo onde dados, sistemas e operação se encontram,
e transformo rotinas manuais em ferramentas que outras pessoas conseguem instalar e usar:

- **aplicativos desktop para Windows**, do primeiro protótipo ao instalador com atualização automática;
- **orquestração de agentes de IA**: vários CLIs trabalhando em paralelo, com contexto compartilhado e regras de acesso;
- **automação de implantação, backup e suporte** com PowerShell, C# e bancos de dados;
- **integrações** com APIs HTTP, MCP, webhooks e WhatsApp;
- **dados**: SQL, Firebird, SQLite e análise com Python para transformar indicadores em decisões.

## Como eu trabalho

- **Produto antes de código.** Penso em quem vai usar: interface, mensagens de erro, instalação e atualização fazem parte da entrega.
- **Entrego em ciclos curtos.** Versões pequenas e frequentes, com notas de versão e publicação automatizada.
- **Segurança e privacidade desde o início.** Dados locais, segredos fora do repositório, permissões explícitas e histórico limpo antes de publicar.
- **IA como equipe, não como atalho.** Uso Codex e Claude Code em paralelo para construir, revisar e testar, sempre validando o resultado.
- **Git como memória.** Commits pequenos, sempre com o porquê, para que pessoas e agentes entendam a história do projeto.

## Além do código

Experiência com **redes de computadores, cibersegurança, suporte técnico e backup e recuperação**. Isso aparece na
forma como desenvolvo: penso em implantação, permissões, falhas, logs, manutenção e em quem vai usar a solução no dia a dia.

**SOLPPE (Solução Parceira Para Empresas)** é a marca das soluções que crio para problemas operacionais reais:
entender a rotina, tirar o atrito e entregar uma ferramenta que se instala, opera e mantém sem complicação.
